## ⟡ Things I keep coming back to

- **Quantum software** — Qiskit, circuits, channel discrimination, and learning what the math is actually saying.
- **Systems & tooling** — online judges, protocols, networking, automation, and tools that remove annoying work.
- **Applied AI** — useful systems over wrapper-for-the-sake-of-wrapper demos.
- **Open source** — reading real codebases, finding the sharp edges, and learning by contributing where I can.
